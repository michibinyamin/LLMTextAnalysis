================================================================================
                        LLM TEXT ANALYSIS APP - SETUP GUIDE
================================================================================

This application is a Streamlit-based tool that uses OpenAI to summarize text, 
extract topics, and classify user intent.

--- 1. PREREQUISITES ---

Before running the app, ensure you have the following:
1. Python Installed (Version 3.8 or higher recommended).
2. An OpenAI API Key (Required to process text).

--- 2. FOLDER SETUP ---

Ensure the following files are in the same folder:
- app.py            (The main application interface)
- llm_utils.py      (The logic for connecting to OpenAI)
- samples.JSON      (Optional: A file containing sample texts for testing)

--- 3. INSTALLATION ---

Open your terminal or command prompt, navigate to this folder, and run the 
following command to install the necessary libraries:

    pip install streamlit openai PyPDF2

--- 4. HOW TO RUN ---

In your terminal, inside the project folder, run:

    streamlit run app.py

This will automatically open the application in your default web browser 
(usually at http://localhost:8501).

--- 5. USING THE APP ---

1. Enter API Key: On the left sidebar, paste your OpenAI API Key.
2. Select Task: Choose "Summarize Text", "Extract Key Topics", or "Classify Intent".
3. Input Data: You can type text manually, select a sample, or upload a PDF/TXT file.
4. Generate: Click the button to view the results.

--- TROUBLESHOOTING ---

* "Module not found": Run the pip install command in Step 3 again.
* "API Error": Ensure your API key is valid and has credits available.
* "File not found (samples.JSON)": The app works without this file, but you 
  won't have pre-loaded examples.
